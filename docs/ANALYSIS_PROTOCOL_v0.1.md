# 心梗后心衰多队列转录组分析方案 v0.1

日期：2026-08-06  
状态：数据可用性审计后的预规格草案；正式建模前尚需冻结。

## 1. 主要问题

心梗入院时的外周血转录信号能否识别 6 个月后发生心衰的患者，且该信号是否呈现可重复的急性期—恢复期时间轨迹？

## 2. 分析层级

### 2.1 主分析

- 队列：GSE59867。
- 样本：有明确 HF/non-HF 标签的入院样本，n=64（HF=34，non-HF=30）。
- 预测因子：入院 PBMC 基因表达。
- 结局：研究者基于 6 个月 LVEF 和 NT-proBNP 定义的 HF/non-HF。
- 主要估计目标：连续表达评分对该二分结局的区分度与校准度。

### 2.2 支持性时间验证

- GSE59867：入院、出院、1月、6月；有患者编号时用混合模型。
- GSE123342：D0、D30、Y1 群体层面验证；找到可审计 subject ID 前不声称配对。
- GSE249812：急性期 n=3、亚急性期 n=5、旧梗期 n=7；仅作 RNA-seq 平台的方向支持，不承担确证性推断。

### 2.3 支持性预后验证

- GSE48060：AMI 复发事件 5，无事件 26。
- 仅对完全锁定的评分估计方向、效应量与置信区间；不重新选特征、调权重或选截点。

### 2.4 单细胞机制解释

- 主用途：确定评分基因的表达细胞来源，区分细胞比例变化与细胞内转录激活。
- 候选：GSE269269，人 PBMC，10 位 AMI 患者（5伴斑块破裂、5不伴），82,550 个细胞。
- 限制：它不含 HF 结局，不能被称为评分的单细胞外部验证。
- 推断单位：患者，使用 patient-level pseudobulk/患者级评分；不把细胞当作独立重复。

## 3. 预处理原则

1. 各队列单独 QC 和标准化。
2. Affymetrix CEL 在队列内 RMA；RNA-seq 优先使用 raw counts，若只能使用 FPKM，限于评分方向验证。
3. 统一到当前人基因标识符，保留每个平台从探针/转录本到基因的映射表。
4. 不拼接表达矩阵后使用 ComBat 并随机拆分。
5. 主模型中的方差过滤、差异筛选、去相关和调参全部放在内层重采样中。

## 4. 主模型与内部验证

### 4.1 候选方法

- 主方法：elastic-net logistic regression。
- 参照方法：无特征筛选的三基因 RNASE1/FMN1/JDP2 模型，以及单基因模型。
- 不作为主结果：随机森林、XGBoost、SVM 或深度学习的最优者竞赛。

### 4.2 重采样

- 外层：重复分层 5-fold CV，初定 50 次重复；保存每个患者的 out-of-fold 预测。
- 内层：5-fold CV 选择 alpha/lambda 及任何特征筛选阈值。
- 稳定性：报告基因入选频率、系数分布与评分相关性；不只报告一次分割的“最佳”结果。

### 4.3 指标

- 主指标：AUROC 及重采样不确定性。
- 次指标：AUPRC、Brier score、calibration slope/intercept。
- 不在主队列中挑选“最佳”截点作为主发现。
- 如无临床表，不计算或声称增量 AUC、NRI、IDI 和 decision-curve net benefit。

## 5. 时间效应与跨队列整合

1. 优先比较急性期与各队列最稳定时点，再评估中间时点。
2. 有可靠 patient ID 的队列用患者随机截距模型；无 ID 队列作独立组对比并降低证据等级。
3. 在基因层面提取标准化效应和标准误，用 REML 随机效应 Meta 分析。
4. 报告 tau²、I²、prediction interval 及 leave-one-cohort-out 后效应；不以“各队列都 P<0.05”作为一致性标准。
5. 必须区分“心梗时间效应 Meta”和“HF 预测”；后者目前只有一个队列。

## 6. 单细胞分析的最小充分集

1. 基础 QC、doublet 检测、样本级质量摘要。
2. 细胞类型注释与关键 marker 人工核对。
3. 冻结的 bulk 评分在各细胞类型中的表达覆盖和患者级 pseudobulk score。
4. 使用患者级细胞比例与细胞内评分分解 bulk 信号。
5. 仅在有清晰先验问题时做转录因子/细胞通讯；不堆叠工具产生表面复杂度。

## 7. 敏感性分析

- 不同探针到基因汇总规则。
- 去除 QC 边界样本。
- 评分是否由一个高权重基因驱动。
- 在可用时调整推断的细胞组成。
- 将已有文献签名（三基因、13基因、4基因）与新评分在同一 out-of-fold 框架下比较。

## 8. 准入/停止准则

- 若 CEL QC 显示 HF 分组与明显技术批次完全混杂，停止预测建模，改为数据限制报告。
- 若重复嵌套 CV 中基因选择极不稳定或校准严重失真，不固化新多基因评分，转而报告通路/模块效应。
- 若外部队列时间方向显著异质，不强行构建单一“恢复轨迹”，改为解释取材/平台/人群异质性。
